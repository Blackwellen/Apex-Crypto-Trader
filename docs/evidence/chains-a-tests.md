## What the tests prove (by requirement)

- **No CERTIFIED / fail closed (registry):** no capability is CERTIFIED anywhere; none can be CERTIFIED without `evidenceRef`; `assertCertified` throws `CapabilityNotCertified` for all 27 chains x 26 capabilities (702 assertions); execution capabilities are only PENDING/UNSUPPORTED; READ_ONLY exists only where `LIVE_EVIDENCE[chain].status === 'PASS'` lists that capability, with `evidenceRef = docs/evidence/chains-a-live-reads.md#<chain>`; BLOCKED evidence yields zero READ_ONLY (`applyLiveEvidence`); UNSUPPORTED is never upgraded.
- **Registry content:** all 12 required EVM networks, Solana mainnet/devnet(+testnet), Sui mainnet/testnet, Aptos mainnet/testnet; chain ids/native symbols/decimals asserted against the values verified from ethereum-lists/chains + live `eth_chainId`; every record has `verifiedFrom`, consistent `unverified`/`unverifiedFields`, `enabled=false`; `registerChains` rejects conflicts, CERTIFIED-without-evidence, enabled records, malformed ids and base-chain collisions; `makeExtraEvmChain` demands a cited source.
- **SQL seed:** committed `0100_seed_chain_registry.sql` equals `renderSeedSql(buildRegistry().records)`; applies to a fresh DB with all chains and 26 capabilities each; READ_ONLY rows equal the TS registry; zero CERTIFIED; zero enabled; re-seeding is idempotent, preserves an operator-set `enabled=true` and never downgrades a CERTIFIED row; table check `certified_needs_evidence` still bites.
- **EVM:** EIP-55 official vectors (checksummed, all-caps, all-lower), bad-checksum rejection; chain-id mismatch rejects and poisons the client (no other call reaches the node); malformed quantities rejected; non-standard string error bodies become typed errors; EIP-1559 next-base-fee rule; maxFee bound and hard cap (`FeeCapExceededError`); feeHistory median tip; fallback to `eth_maxPriorityFeePerGas`; legacy `gasPrice` fallback; L2 data fee kept as a separate component and unknown stacks flagged unknown and the quote marked stale; OP/Arbitrum calldata + decode shapes; receipt/reorg/finality state machine (pending->included->final, reorged, re-included, finality-violation flagged not hidden, finalized-tag-required mode, reverted => failed); per-chain depth policy and `NoFinalityPolicyError` for unconfigured chains; native reserve model; approvals (infinite refused, per-chain allowlist, no hardcoded router/Permit2, over-scope refused, revoke allowed, reset-then-approve, Permit2 exact/short-lived/typed data); simulate (revert decoding, gas buffer/cap, target allowlist).
- **EVM nonce allocator (Postgres):** 100 concurrent `reserve` calls for one (chain, signer) return 100 distinct contiguous nonces (7..106), next_nonce = 107, zero duplicates; idempotent per intent; chains/signers independent; adopts a higher chain nonce; broadcast -> replace (needs >=10% on BOTH fee fields) -> confirm with the original or replacement hash; release only for never-broadcast nonces; released gap reused first; reserved nonces below the chain floor never reused; in-flight limit; DB unique index blocks duplicates even when bypassing the function.
- **Solana:** base58 vectors and 32-byte pubkey validation; fee model (5000/sig, ceil priority on requested CU, bounded Jito tip incl. refusal when cap < minimum, v1 flagged incomplete); compute-budget instruction encoding; rent: legacy constants plus node-derived schedule (`rentParamsFromNode`; live finding that the legacy constant is stale); ATA sizing for SPL and Token-2022 (matches a real mainnet account's lamports); Token-2022 TLV parser + risk analyzer on a REAL recorded PYUSD mint (PermanentDelegate => blocked) and USDC mint, plus synthetic mints for transfer fee (epoch-aware ceil fee with max), hook, default-frozen, pausable, non-transferable, unknown extension; malformed data rejected; blockhash state machine: not expired inside window, expired only when height > lastValid BEFORE a null status query, late landing beats expiry, no regress, failed on error, vanished processed status => reconcile, ambiguous submit and Jito bundle unknown/failed/invalid => reconcile and never rebuild until expiry is proven; RPC client incl. cluster (genesis hash) mismatch rejection, bigint amounts beyond 2^53, jsonParsed token accounts, base64 account decode, simulateTransaction with sigVerify off.
- **Sui:** strict 0x+64-hex addresses; chain-identifier mismatch rejection; recorded real shapes (balance incl. `fundsInAddressBalance`, coins page, shared object, gas price, checkpoint, transaction effects); partial-coin-view refusal; dry-run wrapper and gross/net gas math; transaction status (checkpoint => final; unknown digest => unknown/reconcile). **Coin leases (Postgres):** 100 simultaneous requests for ONE coin object => exactly 1 success, 99 `insufficient`; 100 requests over 10 coins => exactly 10 winners with 10 distinct objects; gas and input coins never the same object; best-fit gas coin; idempotent per intent; release frees; consume burns the version (same or older version is stale, newer is accepted); expired leases keep blocking until resolved (`unused` frees, `consumed` burns); unique partial index holds even when bypassing the function.
- **Aptos:** short/long address normalisation and strict mode; chain-id mismatch rejection; recorded real shapes incl. bare-integer balance with u64 precision; committed (orderless), pending, not-found lookups; gas bound/caps; expiration derived from chain time; status resolution (expired only if chain time passed AND the sequence was not consumed, otherwise reconcile; orderless never claims expiry); simulate wrapper. **Sequence allocator (Postgres):** 100 concurrent reservations => contiguous 42..141; idempotent; independent chains/accounts; replace requires >=10% gas price and later expiry; commit with any attempt hash; release/gap reuse; reconcile; in-flight limit; unique index.
